# Library Management System

## About the Project  
This project is a simple Library Management System built using SQL.  
It is used to manage book details, member information, and track the issue and return of books.  
The system helps in maintaining records in an organized way and retrieving useful information when needed.

---

## Objective  
The main objective of this project is to understand how a library system works using a database.  
It focuses on storing data properly and writing queries to track book lending and returns.

---

## What I Did  
- Created tables for books, members, and loans  
- Used primary key and foreign key to maintain relationships  
- Inserted sample data for books and members  
- Tracked issued books using SQL queries  
- Identified books that are not yet returned  
- Used JOIN queries to combine data from multiple tables  

---

## Tools Used  
- SQL (MySQL)  
- GitHub

## Database Tables  
- **books** – stores book details  
- **members** – stores member information  
- **loans** – stores issued and returned book records
