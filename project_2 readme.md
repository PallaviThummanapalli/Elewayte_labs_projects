# Employee Management and Attendance Tracker

## About the Project  
This project is designed to manage employee details and track their daily attendance using SQL.  
It simulates a basic system used in organizations to store employee information, assign departments,  
and monitor attendance records.

---

## Objective  
The main objective of this project is to understand how employee data is stored and how attendance  
can be tracked and analyzed using SQL queries.

---

## What I Did  
- Created tables for departments, employees, and attendance  
- Established relationships using primary key and foreign key  
- Inserted sample employee and attendance data  
- Used JOIN queries to combine employee and department details  
- Wrote queries to track attendance status  
- Calculated total presence using aggregate functions  

---

## Tools Used  
- SQL (MySQL)  
- GitHub  

---

## Database Tables  
- **departments** – stores department details  
- **employees** – stores employee information  
- **attendance** – stores daily attendance records  

---

## Key SQL Concepts Used  
- Table creation (CREATE TABLE)  
- Primary Key & Foreign Key  
- INSERT statements  
- JOIN operations  
- Aggregate functions (COUNT)  
- GROUP BY  

---

## Sample Analysis  
- Retrieved employee attendance along with department names  
- Counted total present days for each employee  
- Checked attendance status (Present, Absent, Late)  

---
